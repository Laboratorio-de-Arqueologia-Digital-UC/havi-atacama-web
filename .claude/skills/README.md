# Skills de diseño del sitio HAVI Atacama

Estas skills se incluyen para que cualquier agente que trabaje en el repositorio diseñe y revise con el mismo criterio. Se copiaron sin cambios desde sus repositorios, salvo lo indicado, y conservan su licencia.

| Skill | Origen (commit) | Licencia | Para qué se usa aquí |
| --- | --- | --- | --- |
| `impeccable` | [pbakaus/impeccable](https://github.com/pbakaus/impeccable) (f2baa41) | Apache 2.0 | Contexto del producto (PRODUCT.md, DESIGN.md), piso de calidad, crítica y detector de patrones (`npx impeccable detect`). |
| `taste-skill` | [leonxlnx/taste-skill](https://github.com/leonxlnx/taste-skill) (f6b7657) | MIT | Solo `references/copy-tells.md` para revisar textos en inglés. Se quitó la carpeta `assets` (38 MB). |
| `emil-design-eng`, `review-animations`, `break-ui`, `mobile-native`, `prototype` | [emilkowalski/skills](https://github.com/emilkowalski/skills) (715c180) | MIT | Reglas de movimiento, pruebas con contenido extremo y uso en teléfono. |

## Reglas de este proyecto que mandan sobre las skills

- Toda imagen lleva pie y crédito. Se ignora la regla de Taste Skill que prohíbe pies de foto.
- No se usan imágenes de relleno ni fotos de reemplazo: solo material real del proyecto, con su autoría.
- No se reparten paletas ni portadas al azar: la dirección visual es la «C · Realce» (ver DESIGN.md).
- Las ubicaciones de los sitios se muestran con el nivel de detalle que defina el inventario.
